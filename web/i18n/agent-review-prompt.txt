## 必查项（instrument 典型问题）

### 1. 合并拆碎的 t()
同一 UI 文案被拆成多个 t() + 裸 JS 片段的，合并为一个 key + 插值。
- 反例：`finishedOfTotalTasks` + 裸 percent + `.key`（"%)"）
- 正例：单个 `taskProgress`，`defaultValue: "{{finished}} of {{total}} Tasks ({{percent}}%)"`

### 2. 无意义 key
删除或重命名 `.key`、过短无语义 key。

### 3. namespace
- `pages/**` → `useTranslation("labelstudio")`
- `components/**` → `useTranslation("components")`
- `libs/app-common/**` → `useTranslation("app-common")`

### 4. defaultValue
每个 `t()` / `i18next.t()` / `translate()` 必须 `{ defaultValue: "..." }` 对象写法。

### 5. 三元表达式两侧都要 i18n
`condition ? "..." : t(...)`、`condition ? t(...) : "..."`、`condition ? undefined : "..."` 只国际化一侧是漏翻。
- 反例：`{isUpdating ? "Updating..." : t('updatePreview', { defaultValue: "Update Preview" })}`
- 反例：`title={disabled ? undefined : "Drag to resize. Double-click to collapse or expand."}`
- 正例：两侧都 `t()`，或合并为一个带插值的 key

### 5b. instrument 不得破坏 JSX 结构
相邻多个 `<p>` / 含内联 `<a>` 的段落，instrument 后仍应各自独立；第一段 `t()`、第二段 `<Trans>`，不要把 key 塞错标签或吞掉整段。
- 反例：删掉第一个 `<p>`，把第一段的 `t()` 放进第二个 `<p>`，丢失「Start from templates…」
- 正例：两个 `<p>` 各自 `t()` / `<Trans>`

### 5c. instrument 无效 <Trans>（内联链接/强调）
instrument 会把 `<a>` / `<i>` 压成乱码 `i18nKey`（如 `aHrefhttps...`、`1NavigateToTheIdataManageri`），运行时必炸。
- 反例：`<Trans i18nKey="aHref..."><a href="...">Learn more</a></Trans>`
- 正例：段落用 `t()`，链接文字单独 `t()`： `{t('...')} <a href="...">{t('...learnMore')}</a>`
- 或正规 `<Trans defaults="...<0>...</0>" components={[<a href="..." />]} />`
- `yarn i18n:instrument -- --fix-only` 可自动去掉无效 Trans 外壳（保留内部 JSX），再补 t()

### 6. Trans 标签索引与 components 对齐
`<Trans defaults="...<0>...</0>..." components={[<a/>]} />` 中 `<N>` 为 **0-based**，最大 N 必须 `< components.length`。
- 反例：`defaults="...<1>link</1>..."` 但 `components={[<a/>]}`（只有一个元素，应用 `<0>`）
- 正例：`defaults="...<0>link</0>..."` + `components={[<a href="..." />]}`

### 7. 可见 UI 文案不要裸字符串
按钮、标题、提示、banner、空状态等用户可见英文，应走 `t()` / `<Trans>`，不要留在 JSX 字面量里。
特别注意：
- `aria-label`、`placeholder`、`title`、`alt`、`label`、`term` 裸字面量 **或** `title={...}` 表达式内裸字符串
- `<p>` / `<span>` 等标签内裸英文句子（含多行、内联链接前的段落文本）

### 8. 模块级英文常量与页面元数据
若常量（如 `LARGE_CONFIG_MESSAGE`）会渲染到 UI，改为 `t()` / `i18next.t()` 或在组件内用 hook 取值；不要 import 裸英文字符串到 JSX。
侧边栏/页面标题：`Component.title` / `Component.menuItem` 不得裸 `"General"` 等字面量，应与其他 Settings 页一致写 `Component.title = i18next.t("...", { defaultValue: "..." })`（`yarn i18n:check` 规则 `bare-module-ui-property`）。

### 9. 不要翻译
URL 路径、React Router `path`、Tailwind / `className` 类名、testid、键盘码、内部技术标识；`api.invoke("methodName")` 等 API 方法名、路由名、事件名保持原字符串字面量，**不要**包 `t()` / `i18next.t()`；`CreateProject/Config/tags.js`、`recipes.js`（标注 XML）不国际化。

### 10. 保留原有注释
只改 i18n 相关逻辑，尽可能保留已有注释。

### 11. 不要手改 locale
不要编辑 `web/locales/*.json`（后续 extract 会生成）。
